Название проекта "Система внутренних заявок сотрудников"

Проект создан для упрощения процесса подачи заявок и создания удбного интерфейса, чтобы было несложно и удобно создавать, редактировать и просматривать свои заявки

Целевая аудитория-Сотрудники офисных предприятий.


Сущности, используемые в проекте:

1. Сотрудник
2. Заявка
3. Категория
4. Исполнитель


Основные функции

1. Создание заявки
2. Редактирование заявки
3. Просмотр своих заявок
4. Отмена заявки


План развития

1. Выбор проекта
2. Описание документации, разработка плана работ
3. Реализация проекта, написание кода, реализация основного функционала приложения
4. Тестирование
5. Исправление ошибок и багов
